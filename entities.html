HTML Special Character Entities Demonstration

1. Less Than: Use &lt; to render < (e.g., <div>)

2. Greater Than: Use &gt; to render > (e.g., 5 > 3)

3. Trademark: Use &trade; to render ™ (e.g., M-Tech™)

4. Registered Trademark: Use &reg; to render ® (e.g., Python®)

5. Infinity: Use &infin; to render ∞ (e.g., Knowledge is ∞)
